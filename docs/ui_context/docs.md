# 飞书云文档界面说明
## 整体布局
```
┌────────────────────┬─────────────────────────────────────────────────────┐
│  左侧文档导航栏    │                文档编辑/预览区                      │
└────────────────────┴─────────────────────────────────────────────────────┘
```
---
## 左侧文档导航栏（最左列，从上到下）
| 图标/区域 | 功能 |
|----------|------|
| 云文档 | 云文档主入口，展示我的文档、共享文档、收藏等 |
| 新建 | 新建文档、表格、幻灯片、表单、白板等 |
| 最近 | 最近访问/编辑的文档列表 |
| 我的文档 | 个人创建与管理的文档根目录 |
| 共享给我 | 他人共享的文档集合 |
| 收藏 | 标记收藏的快捷访问列表 |
| 回收站 | 已删除文档可恢复/清空 |
| 搜索文档 | 全局搜索文档（Ctrl+K） |
| 文件夹树 | 多级文件夹目录管理 |
---
## 文档列表区（中间/主区域）
```
┌─────────────────────────────────────────────────────┐
│ 云文档                    [新建] [筛选] [视图切换]   │
├─────────────────────────────────────────────────────┤
│ 🔍 搜索文档 Ctrl+K                              │
├─────────────────────────────────────────────────────┤
│ [列表/网格视图]  文档/文件夹列表...                 │
└─────────────────────────────────────────────────────┘
```
- **新建按钮**：顶部右侧「新建」，支持：
  - 新建文档
  - 新建表格
  - 新建幻灯片
  - 新建表单
  - 新建白板
  - 导入本地文件
- **搜索框**：顶部下方，支持按标题/内容/创建人搜索
- **筛选**：按类型、创建时间、所有者筛选
- **视图切换**：列表视图 / 网格视图
- **排序**：按修改时间、创建时间、名称排序
---
## 文档编辑/预览区（右侧主区域）
### 顶部工具栏
| 图标 | 功能 |
|------|------|
| ← 返回 | 返回文档列表 |
| 文档标题 | 点击重命名 |
| 分享 | 分享文档、设置权限、复制链接 |
| 🔍 搜索 | 搜索当前文档内容 |
| 星标 | 收藏/取消收藏 |
| 历史 | 查看版本历史、恢复历史版本 |
| 更多 | 导出、打印、移动、删除、权限设置等 |
### 编辑区工具栏
| 控件 | 功能 |
|------|------|
| 样式 | 正文、标题1-6、引用、代码块、列表 |
| 格式 | 加粗、斜体、下划线、删除线、颜色 |
| 插入 | 图片、表格、链接、代码块、分割线、引用、任务列表 |
| @ | @同事、文档、日历、群聊 |
### 插入内容块（Agent 操作须知）
- 将鼠标悬停在某一行左侧，行首会出现「**+**」按钮，点击打开插入菜单
- 可插入：图片、表格、代码块、分割线、附件等
- **不要**在编辑区内 `type(content='/')` 来触发插入菜单，该方式对 Agent 无效

### 文档编辑区
- 支持**富文本+Markdown**
- 支持多人实时协同编辑，显示在线用户光标
- **全选文档内容**：`Ctrl+A`
- **清空文档内容**：`Ctrl+A` → `Delete`，或 `Ctrl+A` 后直接 `type` 覆盖
- 不要用坐标 drag 选文本，优先用键盘快捷键
- 支持评论、批注、建议模式
### 右侧边栏（可展开/收起）
| 面板 | 功能 |
|------|------|
| 评论 | 查看/添加评论、回复、resolve |
| 历史 | 版本历史、编辑记录、对比 |
| 权限 | 查看/设置协作者权限（可阅读/可编辑/管理员） |
| 任务 | 文档内关联任务、待办 |
---
## 云文档特有功能
- **实时协作**：多端多人同时编辑，无冲突自动合并
- **权限体系**：组织内公开/指定人可看/可编辑/链接分享
- **版本历史**：自动保存，支持回溯与恢复
- **插入丰富内容**：表格、图表、视频、投票、思维导图、表单
- **跨应用联动**：插入飞书聊天记录、日历、任务、仪表盘
---
## 常用操作路径速查
| 目标操作 | 最短路径 |
|----------|----------|
| 新建文档 | 云文档首页 → 右上角「新建」→ 文档 |
| 搜索文档 | Ctrl+K → 输入关键词 → 回车 |
| 分享文档 | 文档顶部「分享」→ 设置权限 → 复制链接 |
| 插入表格/图片等 | 悬停目标行左侧 → 点击「+」按钮 → 选择类型 |
| 清空文档内容 | `Ctrl+A` → `Delete` |
| 查看历史版本 | 文档顶部「历史」→ 选择版本 → 预览/恢复 |
| 收藏文档 | 文档顶部点击「星标」 |
| 重命名文档 | 点击顶部文档标题 → 输入新名称 |
| 导出文档 | 文档顶部「更多」→ 导出 → 选择格式(PDF/Word等) |
