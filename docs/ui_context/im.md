# 飞书 IM 界面说明

## 整体布局

```
┌─────────┬──────────────────┬──────────────────────────────────────────┐
│  左侧   │   会话列表区     │            聊天内容区                    │
│  导航栏 │                  │                                          │
└─────────┴──────────────────┴──────────────────────────────────────────┘
```

---

## 左侧导航栏（最左列图标，从上到下）

| 图标 | 功能 |
|------|------|
| 消息 | IM 主界面，点击后激活会话列表 |
| 知识库 | 知识库入口 |
| 工作台 | 应用工作台 |
| 通讯录 | 联系人管理 |
| 视频会议 | 视频会议入口 |
| 日历 | 日历入口 |
| 云文档 | 云文档入口 |
| 飞书小助手 | AI 助手 |
| 更多 | 折叠的其他功能 |

---

## 会话列表区（中间列）

- **顶部搜索框**：显示「搜索 Ctrl+K」，点击或按 Ctrl+K 打开全局搜索
- **新建按钮**：搜索框右侧的铅笔/编写图标，点击后弹出菜单：
  - 发起单聊
  - 创建群组
  - 创建话题群
- **会话列表**：按时间排序，显示头像、名称、最新消息预览和时间

---

## 聊天内容区（右侧主区域）

### 顶部工具栏（右上角图标，从左到右）

| 图标 | 功能 |
|------|------|
| 🔍 搜索 | 搜索本会话内消息记录 |
| 📞 语音通话 | 发起语音通话 |
| 📹 视频通话 | 发起视频通话 |
| 👥 创建群组 | 以当前单聊成员为基础创建群聊 |
| 📅 查看日历 | 查看与对方的共享日历 |
| ⋯ 更多 | 下拉菜单：添加标签页、查看任务、设置 |

### 消息记录区（中间主体）

消息气泡悬停时，气泡**右侧**出现操作图标（从左到右）：

| 操作 | 说明 |
|------|------|
| 😊 表情 | 对消息添加 emoji 反应 |
| ↩ 回复 | 引用并回复该消息 |
| ➡ 转发 | 转发到其他会话 |
| 💬 创建话题 | 基于该消息开一个话题讨论 |
| ⋯ 更多 | 展开子菜单：多选、标记、Pin、置顶、复制消息链接、翻译、删除、添加任务、导出到文档、快捷应用 |

### 底部消息输入栏

```
[格式] [😊] [@] [截图▼] [更多▼] ............输入区............ [展开] [发送▼]
```

| 控件 | 位置 | 功能 |
|------|------|------|
| A 格式工具栏 | 最左 | 展开/收起富文本格式工具栏（加粗、斜体、列表等） |
| 😊 表情 | 左侧 | 插入 emoji |
| @ 选择成员 | 左侧 | 触发成员 @ 列表（与输入「@」等效） |
| 📷 截图▼ | 左侧 | 下拉：提取文字、滚动截屏、录屏、截图 |
| ⋯ 更多▼ | 左侧 | 下拉：图片/视频、本地文件、云文档、日程… |
| 输入区 | 中间 | 文字输入，支持粘贴图片 |
| ↕ 展开 | 右侧 | 展开输入框高度 |
| 发送▼ | 最右 | 点击发送（或按 Enter）；下拉箭头切换为「定时消息」 |

> **发送快捷键**：默认 Enter 发送，Shift+Enter 换行。

---

## 群聊特有功能

- **顶部**：群名称 + 成员头像列（点击查看成员列表）
- **@ 提及**：输入「@」后出现成员选择浮层，方向键选择后 Enter 确认
- **公告**：顶部 PIN 区域可能显示群公告
- 消息输入栏额外有「入群红包」等群专属功能（在「更多」菜单）

---

## 常用操作路径速查

| 目标操作 | 最短路径 |
|----------|----------|
| 搜索并进入单聊 | Ctrl+K → 输入姓名 → 回车/点击 |
| 在当前会话发送消息 | 点击输入框 → 输入 → Enter |
| 发送图片 | 输入栏「更多」→ 图片/视频，或直接粘贴 |
| 转发消息 | 悬停消息 → 右侧「转发」图标 |
| 创建群聊 | 会话列表顶部「新建」图标 → 创建群组 |
| @ 提及成员 | 输入「@」 或点击输入栏「@」图标 |
| 发送定时消息 | 「发送」按钮旁下拉箭头 → 定时消息 |
